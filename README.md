This project builds and evaluates predictive models to estimate house prices based on features such as location, size, number of rooms, age of the property, and more. It covers the full data science pipeline — from data cleaning and exploratory analysis to model training, evaluation, and deployment-ready inference.
Features:
Exploratory Data Analysis (EDA) with visualizations
Data preprocessing — handling missing values, outliers, and encoding
Feature engineering and selection
Model training using multiple regression algorithms (Linear Regression, Random Forest, XGBoost, etc.)
Hyperparameter tuning with GridSearchCV / RandomizedSearchCV
Model evaluation using RMSE, MAE, and R² score
Final model export using joblib / pickle
